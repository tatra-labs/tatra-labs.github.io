# Foundation books (Markdown)

## Layout

- **Catalog metadata** — `data/foundation/books/<slug>.json`  
  Use `"reader": "markdown-toc"`, `"contentRoot"`, and `"tocFile"` for a full book with a generated TOC.
- **Table of contents (JSON tree)** — e.g. `data/foundation/books/deep-learning-toc.json`  
  Generated by `tools/generate_dl_toc.py` from `tools/dl-toc-source.txt` (edit the source, re-run the script).
- **Section bodies** — one Markdown file per TOC leaf, e.g.  
  `content/foundation/books/deep-learning/sec-1-1.md`  
  Must match the `"file"` field in the TOC JSON.

## Deep Learning

- TOC follows *Deep Learning* (Goodfellow, Bengio, Courville) section numbering.
- Add or edit Markdown under `content/foundation/books/deep-learning/`.
- Supported in Markdown: **headings**, **paragraphs**, **images**, **lists**, **code fences**, **inline/display math** (`$...$`, `$$...$$`, `\[...\]`).

## Regenerate TOC after editing `dl-toc-source.txt`

```bash
python tools/generate_dl_toc.py
```

## New book (boilerplate)

1. Copy `data/foundation/books/deep-learning.json` and `deep-learning-toc.json` patterns, or start from a minimal `tocFile` with `prelude` / `parts` / `flatSections`.
2. Add `content/foundation/books/<slug>/sec-*.md` files.
3. Register the book in `data/foundation/books-list.json`.
