**Kaiming He, Xiangyu Zhang, Shaoqing Ren, Jian Sun · 2015 · [arXiv:1512.03385](https://arxiv.org/abs/1512.03385)**

By late 2015 depth was clearly worth something — VGG and GoogLeNet had both bought accuracy with layers — but the returns stopped abruptly. Somewhere past twenty layers, adding more made the network worse, and the failure did not look like overfitting. On CIFAR-10 a 56-layer plain convolutional network had higher **training** error than a 20-layer one. A model that cannot fit its own training set is not memorizing; it is failing to optimize. The paper sharpens this into a construction: take a trained shallow network, append layers that compute the identity, and the deeper network must match the shallower one exactly. Such a solution exists in the parameter space. SGD did not find it.

The fix changes what each block has to represent. A standard block maps `x` to some `H(x)`. A residual block computes `y = F(x, {W_i}) + x`: the stacked layers produce `F`, and the input is added back elementwise. The block's job is now the *difference* between its input and the wanted output. If the useful thing is to leave the signal alone, `F` only has to go to zero — push the weights toward zero, which initialization and weight decay already favour. Under the plain formulation the same behaviour requires several layers of nonlinearity to conspire into an exact identity, a far harder point to hit.

The identity shortcut adds no parameters and no multiplies. Where a block changes channel count or spatial size it becomes a projection, `y = F(x, {W_i}) + W_s x`, a `1x1` convolution with matched stride. The deepest models use a bottleneck block — `1x1` to cut channels, `3x3` at the reduced width, `1x1` to restore — so cost stays flat as depth grows. The measurements separate cause from correlation. At 18 layers, where plain nets train fine, the two are level: 27.94% top-1 for plain, 27.88% for residual. At 34 layers the plain net degrades to 28.54% while ResNet-34 improves to 25.03%. ResNet-152 runs at 11.3 billion FLOPs, below VGG-16 and VGG-19 at 15.3 and 19.6 billion. An ensemble reached 3.57% top-5 on the ImageNet test set and first place at ILSVRC 2015, and the same features gave a 28% relative improvement on COCO detection.

What changed is that the shortcut stopped being an architecture choice and became default wiring. The construction outlived vision: a transformer's residual stream is the same object, with attention and MLP blocks writing increments into a vector carried forward unchanged. The paper earns its place as a training result that happened to be demonstrated on images.

> Make "do nothing" the easy thing for a block to express, and depth stops fighting the optimizer.

**What did not survive:** the explanation, and the block itself. The authors are candid that they have none — "the reason for such optimization difficulties will be studied in the future" — so the result arrived without a settled account of why plain nets fail. Depth also stopped paying: the 1202-layer CIFAR network reached 7.93% test error against the 110-layer network's 6.43%, and that 110-layer net still needed a warmup at learning rate 0.01 for roughly 400 iterations because 0.1 was too large to start converging.
