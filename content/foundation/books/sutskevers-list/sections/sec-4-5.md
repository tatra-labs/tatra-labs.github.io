**Adam Santoro, Ryan Faulkner, David Raposo et al. · 2018 · [arXiv:1806.01822](https://arxiv.org/abs/1806.01822)**

The memory architecture of 4.1 — a controller, a matrix of slots, heads that address slots by content — has a gap: the slots never touch each other. A read is a lookup: a weighted average of rows chosen by similarity to a query. Nothing compares slot 3 to slot 7. When a task turns on how two stored items relate, the controller must fetch them on separate timesteps and rebuild the relation in its own recurrent state, one pair at a time. Santoro et al. built a task to expose this: show the model 8 randomly labelled 16-dimensional vectors, then ask which is the N-th farthest from vector M. Neither an LSTM nor a DNC exceeded 30% best-batch accuracy.

The Relational Memory Core replaces lookup with interaction. Memory is a matrix `M` of `N` rows, one row per slot. At each timestep the input is appended as an extra row and the whole stack passes through multi-head dot-product attention: queries from the memory rows, keys and values from the memory rows plus the input. Each slot's proposed new content is a softmax-weighted combination of every other slot and the new observation — `softmax(QK^T / sqrt(d_k))V`, the all-pairs interaction of 4.4 with learned weights, turned sideways across a fixed set of slots rather than backwards along a growing sequence. A residual connection and a row-wise MLP with layer normalisation follow, so slots stay compartmentalised through the feedforward step.

The recurrent half is ordinary LSTM machinery applied per row. Attention proposes; gates decide how much lands: `m_i,t = σ(f_i,t + b̃_f) ∘ m_i,t−1 + σ(i_i,t) ∘ g_ψ(m̃_i,t)`, gates computed from the input and the previous slot contents, `b̃_f` a learned forget bias. Slots persist, get overwritten under gating, and — the new part — see each other on the way. Compute per step is set by `N`, not by sequence length, and the memory never grows.

On the N-th farthest task the RMC reached 91%. It also took state-of-the-art perplexity on WikiText-103 (31.6 test), Project Gutenberg (42.0) and GigaWord v5 (38.3) — a drop of 1.4 to 5.4 perplexity over the best published results, the paper says, a 5-12% relative gain. The architecture went nowhere. The idea inside it did: self-attention is useful as an operation on a model's *state*, not only on its input sequence. Every later attempt to give a Transformer a compressed recurrent memory works the same seam.

> Memory gets more useful when its contents can be compared against each other rather than only retrieved one at a time.

**The caveat:** the language modelling numbers — the paper's most cited result — came from a model with one memory slot. The appendix reports "2500 total units, 4 heads, 1 memory, a 5-layer MLP, and 1 attention block", selected on WikiText-103 validation error. With a single slot there is no slot-to-slot attention, so the mechanism the paper is named for contributed nothing there; the gain came from attention over the input and the gated MLP. The relational claim rests on the synthetic tasks and the RL domains, and that evidence is narrower than it looks: the RMC still solved N-th farthest at 32 dimensions, but only for a few seeds and configurations, the paper notes.
