**Geoffrey E. Hinton & Drew van Camp · 1993 · [COLT '93](https://www.cs.toronto.edu/~hinton/absps/colt93.pdf)**

Start with the problem, because the machinery only makes sense once you have it. A neural network learns by adjusting numbers called **weights** — 521 of them in this paper, billions in a modern one. Give a network a small training set and it will cheerfully memorise every example, noise included, then fail on anything new. That is **overfitting**, and every fix for it is a version of the same move: stop the network using its full freedom.

By 1993 those fixes were structural. Cut connections, so there are fewer weights to abuse. Tie weights together so several must share one value. Or round each weight to one of a fixed set of bins and charge $-\log p$ for the bin it lands in. That last expression is just the standard way of turning a probability into a price in bits: something that happens half the time costs one bit to say, a quarter of the time costs two. It works, but it has no smooth slope, so gradient descent cannot follow it downhill. **Weight decay** — quietly pulling every weight toward zero — did work, and was justified mostly by the fact that it worked. Even the best method of the day, an adaptive mixture-of-Gaussians codebook, prices a weight by how likely its value is and ignores how *precisely* it has to be stated before the network's answers change. Hinton and van Camp call that "a terrible waste of bits."

**Their frame is a transmission, and it is worth holding on to.** A sender can see the inputs and the correct answers. A receiver sees only the inputs. The sender must get the answers across in as few bits as possible. So they send the weights, and then the leftover error on each training case — the **residual**, the gap between the network's guess and the truth. The receiver runs the network and applies the corrections, recovering the answers exactly. Total cost: bits for the weights, plus bits for the misfits.

That frame quietly re-derives the objectives everyone already used. Code the residuals under a bell curve centred on zero and the price you get is squared error. Code the weights under another bell curve and the price is weight decay. Weight decay *is* this method, with both bell-curve widths frozen in advance by hand.

**The new idea is to stop freezing them.** Replace each weight with a small distribution $Q$ — one mean, one variance, no correlations between weights. A weight is no longer a number but a number with an admitted margin of error, and a weight the network barely cares about is allowed a wide margin.

Now count the bits honestly. The sender spends random bits drawing a precise value out of $Q$ to within a fine tolerance $t$, then states that value under a prior $P$ that both parties agreed on beforehand, at a cost of $-\log t - \log P(w)$. Here is the trick. Given the sampled weights and the residuals, the receiver can rerun the very same learning algorithm, recover $Q$, and from $Q$ plus the value work out every random bit the sender spent on the draw. Bits the receiver can reconstruct are bits nobody had to send, so they come back as a refund. What survives is the expected net cost, $\int Q(w) \log \frac{Q(w)}{P(w)} \thinspace dw$ — the **KL divergence**, which measures how far the distribution you ended up with has moved from the one you started out assuming. Expected misfit under $Q$ plus $\operatorname{KL}(Q \parallel P)$ is the quantity now called the variational free energy.

Two approximations make it computable. $P$ is an adaptive mixture of five Gaussians fitted during training, so the exact divergence is swapped for an upper bound on it, and the expected squared error is pushed through a precomputed table — exact only for a network with one hidden layer and linear outputs.

The one task tried was predicting peptide effectiveness: `128` inputs, `105` training cases, `420` test cases, `4` hidden units, `521` adaptive weights. Relative error, scored against simply guessing the training mean, was `0.286`, against `0.967` for the same network with no penalty at all and `0.317` for the best simple weight decay. The objective, not the number, is what earns the paper its place. Expected log-likelihood plus a divergence to a prior is exactly what the variational autoencoder and Bayes by Backprop would later maximise, and the coding derivation gives that divergence a meaning the purely Bayesian reading lacks: it counts the bits the model costs to send.

> Bits spent specifying a weight are refundable if the receiver can rederive the distribution it was drawn from, so a noisy weight's real cost is exactly $\operatorname{KL}(Q \parallel P)$.

**The caveat the authors name themselves:** the shortest total description was reached by a degenerate solution — every weight except the output bias equal and negative, relative error about `1.0`. They call it "a serious embarrassment for the Minimum Description Length Principle or for our method of describing the weights." The `0.286` came from climbing out of that basin by hand, ramping the weight-cost coefficient from `.05` to `1.0` on a twelve-step schedule. The reported number is not the MDL optimum.
