**A. Shen, V. A. Uspensky, N. Vereshchagin · 2017 · [AMS Surveys 220](https://bookstore.ams.org/surv-220)**

Both preceding entries measure a model by the length of a description, and both leave that length relative to a code chosen in advance. Any string can be given a one-bit codeword by a code built around it. Shannon entropy does not close the gap, because entropy is a property of a distribution and not of an object: it says nothing about whether `0101010101` is more regular than a coin-flip string of the same length. Until the mid-1960s there was no definition of the complexity of one particular finite object. Solomonoff, Kolmogorov and Chaitin arrived at one independently, and this textbook is the standard account of what followed.

The definition is short. Fix a universal machine `U`; `C(x)` is the length of the shortest program `p` with `U(p) = x`. The machine looks arbitrary, and the **invariance theorem** rescues it: for any other description method `V` there is a constant `c` with `C_U(x) <= C_V(x) + c` for every `x`. The constant is the length of an interpreter for `V` written for `U`, so it depends on the two languages and not on the data: complexity is well defined up to an additive constant. A counting argument does the rest: there are fewer than `2^n` programs shorter than `n` bits, so most `n`-bit strings satisfy `C(x) >= n - O(1)`. Incompressibility is the normal case.

`C` is not computable, only upper semicomputable — run all programs in parallel, lower the estimate whenever a short one halts on `x`, and never learn when to stop. The proof is Berry's paradox made effective: a program of roughly `log n` bits could search for the first string with `C(x) > n` and print it. From there the book builds algorithmic randomness. Martin-Löf calls an infinite sequence random if it passes every effectively enumerable statistical test; the Levin-Schnorr theorem shows this holds exactly when the prefix complexity `K` of its length-`n` prefix stays within a constant of `n` for all `n`. Plain `C` cannot state that condition, because it dips below `n` infinitely often for every sequence, which is why the middle chapters move to prefix-free codes and the a priori probability `m`, with `K(x) = -log m(x) + O(1)`. The chapter on algorithmic statistics rebuilds the previous section's two-part code without a chosen encoding: name a finite set containing `x`, then give the index of `x` inside it. MDL is that split with the model class restricted to something computable.

The book earns its place by supplying the ceiling: every practical compressor, `gzip` or a transformer, is an attempt on a quantity proved here to be unreachable. 511 pages, exercises throughout, translated from the authors' Russian textbook.

> Compression has a well-defined optimum, and it is uncomputable.

**The caveat:** the `O(1)` is load-bearing and unbounded. Invariance is asymptotic, and an adversarial choice of `U` inflates the constant arbitrarily, so `K(x)` for a fixed finite string is not a number anyone can pin down. Nothing here yields an algorithm, and there is no bound on the gap between a trained model's compression and `C(x)`. The book also contains no machine learning — no networks, no generalisation bounds. The connection to the rest of this list is one the reader supplies.
