**Chen, Kingma, Salimans, Duan, Dhariwal, Schulman, Sutskever, Abbeel · 2017 · [arXiv:1611.02731](https://arxiv.org/abs/1611.02731)**

Every other section here asks where information is stored. This one asks what a store is *allowed* to hold.

Some background first. A **variational autoencoder** has an encoder that compresses each example into a short code $z$, and a decoder that reconstructs the example from it. The hope is that $z$ ends up holding the meaningful, global properties of the data. By 2016 several groups had bolted a powerful autoregressive decoder — one that predicts each pixel or word from the ones before it — onto a VAE, and found the code simply *unused*. Bowman et al. documented it for sentences: the term measuring how much the code departs from its default falls to zero, the encoder's output collapses onto that default, and the model becomes an ordinary language model with a decorative encoder attached.

The accepted explanation was an optimisation failure. Early in training the code carries little information, ignoring it is cheap, and gradient descent never climbs back out of that hole. The fixes were correspondingly procedural: anneal the offending term, or cripple the decoder with dropout.

**This paper answers that a perfect optimiser would do exactly the same thing.** Read the VAE's objective as a code length and it becomes a two-part code — send $z$, then send whatever the decoder cannot predict from it. Bits-back coding, Hinton and van Camp's argument from the opening chapter of this list, observes that the sender's *choice* of $z$ itself carries a secondary message the receiver can recover by rerunning the encoder. Rearranged, the true expected length is the entropy of the data plus a surcharge for every nat routed through an imprecise posterior.

Now the conclusion is forced. **If the decoder can already model the data without $z$, then the ideal code is no code**, the surcharge vanishes, and collapse is the optimum rather than a failure to reach it. What the decoder models locally stays local. Only the remainder has any reason to travel through $z$.

**And that hands over the knob.** Replace the decoder's full history with $p(x_i \mid z, x_{\text{WindowAround}(i)})$ — a PixelCNN that can only see a small patch above and to the left of pixel $i$. Whatever that window predicts stays out of the latent; anything longer-range has nowhere to travel but through $z$. **The receptive field becomes a dial for what the code is forced to carry.**

On statically binarised MNIST, with a six-layer masked-convolution decoder and a 64-dimensional code, the latent carried 13.3 nats (19.2 bits), against 37.3 bits for the identical VAE with a decoder that sees no history at all. Decompressions keep the digit's global shape; none is exact, and the individual pixels usually differ. On CIFAR10, widening the window from 4x2 to 7x4 leaves the code holding progressively rougher shape as the decoder takes over more of the structure; restricting the window to grayscale forces colour back into the code.

A second change swaps the usual posterior for an autoregressive-flow prior: equivalent along the encoder path, but with a deeper generator at no extra training cost. Together they gave 79.03 nats on statically binarised MNIST, 77.36 on Caltech-101 Silhouettes and 2.95 bits/dim on CIFAR10. It earns its place because this list's opening chapter does load-bearing work here: a 1993 coding argument predicts an architecture's failure mode and hands over the knob that fixes it.

> The decoder's receptive field is a specification of what the latent code is not permitted to know.

**The caveat:** the argument is asymptotic, as the paper says — it describes the optimum, not the path to it. Training still needed free bits at 0.01 nats per dimension, plus a softened variant on CIFAR10, so the optimisation problem it demoted did not actually go away. The window is hand-chosen per dataset, and when the choice is wrong it shows: on OMNIGLOT, where small patches carry real meaning, the authors report that semantics are not preserved in some decompressions. Latent-variable image models later lost density estimation to diffusion. The collapse diagnosis endured.
