**Fei-Fei Li, Andrej Karpathy, Justin Johnson · 2015–2017 · [cs231n.github.io](https://cs231n.github.io/)**

Every other item on this list is a paper, and a paper is written to be read once: it states a loss, names an architecture, reports a number. It does not say what to do when a gradient check disagrees in the fourth decimal place, or how to distinguish a bad initialisation from a bad learning rate. Before CS231n that knowledge lived inside lab groups and moved by sitting next to someone. Karpathy co-designed the class with Fei-Fei Li and was its primary instructor in 2015 and 2016, with Justin Johnson co-teaching; enrolment went from 150 students in 2015 to 750 in 2017, and the notes went public.

The organising idea in the notes is that backpropagation is local. "Every gate in a circuit diagram gets some inputs and can right away compute two things: 1. its output value and 2. the local gradient of its output with respect to its inputs" — and the gates do this "completely independently without being aware of any of the details of the full circuit that they are embedded in." The backward pass multiplies the incoming gradient into each local gradient, stage by stage; nothing is differentiated symbolically end to end. The assignments make that structure the actual code: each layer is a pair of numpy functions, a forward returning an output and a cache, a backward taking `dout` and that cache and returning `dx, dw, db`. Batch normalisation, dropout and convolution are each written from scratch, first naively, then vectorised.

Convolution arrives as a constrained matrix multiply. Output spatial size is `(W - F + 2P)/S + 1` for filter size `F`, padding `P`, stride `S`. Parameter sharing is worked with real numbers on AlexNet's first layer, using the `227x227x3` input the stride arithmetic requires rather than the 224 the paper states: `11x11` filters at stride 4 give `55x55x96` — 290,400 neurons at 363 weights and one bias each, so 105,705,600 parameters unshared, and 34,848 weights plus 96 biases once one filter is shared across every position in a depth slice. `im2col` gets the same treatment: it stretches each local region into a column so the layer becomes one dot product handed to BLAS, at the cost of duplicating input data in memory. Debugging is content rather than folklore — relative error above `1e-2` usually means the gradient is wrong, `1e-7` or below is fine, and the ratio of update magnitude to weight magnitude should sit near `1e-3`.

A course earns its slot here because it is the only entry that cannot be completed by reading. The others describe results; this one produces a working `conv_backward_naive` and a person who knows why it was slow. It also supplied the shared vocabulary — receptive field, depth slice, babysitting the learning process — that the papers above assume without defining.

> A layer is a forward function plus its local gradient; every network is bookkeeping over that pair.

**What did not survive:** the notes stopped growing. The public modules end at convolutional networks, while the current assignments run through Transformers and diffusion models with no notes behind them. Public lecture video ends with the 2016 and 2017 recordings; later ones sit on Canvas for enrolled students. The course still runs, now under the name Deep Learning for Computer Vision, but the freely available half of it is largely a 2017 artefact.
