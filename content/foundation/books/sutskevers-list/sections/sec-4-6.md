**Justin Gilmer, Samuel S. Schoenholz, Patrick F. Riley, Oriol Vinyals, George E. Dahl · 2017 · [arXiv:1704.01212](https://arxiv.org/abs/1704.01212)**

By 2016 there were at least eight neural architectures for molecular graphs — Duvenaud's differentiable fingerprints, Li's gated graph neural networks, Battaglia's interaction networks, Kearnes' graph convolutions, Schütt's DTNN, and the spectral line running from Bruna through Defferrard to Kipf and Welling. Each arrived with its own notation, its own input features, its own benchmark.

**That is a worse problem than it sounds.** With everything varying at once, there was no way to tell whether one model beat another because of its architecture or because someone had hand-built better input features and spent longer tuning it. And the application was real: the quantum-chemistry calculation for a single nine-heavy-atom molecule in QM9 takes about an hour on one core of a Xeon E5-2660, so a learned stand-in is genuinely worth having. Nobody could say which of the eight designs deserved the engineering effort.

**The move is to write all eight as the same algorithm with three learned functions plugged into it.** A *message* function $M_t(h_v^t, h_w^t, e_{vw})$ decides what neighbour $w$ sends to node $v$ along the bond between them. Incoming messages are summed, $m_v^{t+1} = \sum_{w \in N(v)} M_t(\cdot)$. A *vertex update* $U_t(h_v^t, m_v^{t+1})$ folds that sum back into the node's own state. Run that for $T$ rounds — so information spreads $T$ bonds outward — and then a *readout* $R(\lbrace h_v^T \rbrace)$ turns the whole set of node states into one prediction for the molecule, order-free for [the reason set out two sections back](/foundation/book/sutskevers-list?section=sec-4-3). Every prior model is just a choice of those three. Spectral convolutions are one message function; interaction networks are another.

Having named the slots made it cheap to try better fillings. The message function becomes an **edge network**: a small MLP maps the bond's feature vector to a $d \times d$ matrix, and the message is that matrix applied to the neighbour's state — so bond type *conditions a transformation* rather than being tacked on as an extra input feature. The update is a GRU. The readout is set2set from earlier in this chapter. Two structural additions fight the fact that $T$ rounds can only reach $T$ bonds away: virtual edges between non-bonded atoms, and a master node wired to every atom at once. The $d \times d$ matrices are expensive, so node embeddings are split into $k$ towers that message-pass separately and mix afterwards; at $k = 8$, $n = 9$, $d = 200$ this halved inference time.

The best model predicts to within chemical accuracy on 11 of 13 QM9 targets. But the framework is the reason those ablations mean anything at all — one codebase, one feature set, one tuning protocol, so a difference in the results is a difference in the model. The message/update/readout triple became the vocabulary of the field and the object model of the libraries that followed.

> Most graph neural networks are the same algorithm with three plug-in functions, and naming the slots is what makes them comparable.

**The caveat:** QM9 caps at nine heavy atoms, and the paper says plainly that generalising to larger molecules looks hard. The reason is specific: the distribution of pairwise distances depends heavily on how many atoms there are, and the most successful spatial variants build a fully connected graph, so the number of incoming messages grows with the molecule. No train-small, test-large experiment is reported; building one is listed as future work. The abstraction survived. The specific network is not what anyone runs now.
