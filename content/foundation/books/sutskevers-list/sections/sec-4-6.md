**Justin Gilmer, Samuel S. Schoenholz, Patrick F. Riley, Oriol Vinyals, George E. Dahl · 2017 · [arXiv:1704.01212](https://arxiv.org/abs/1704.01212)**

By 2016 there were at least eight neural architectures for molecular graphs — Duvenaud's differentiable fingerprints, Li's gated graph neural networks, Battaglia's interaction networks, Kearnes' graph convolutions, Schütt's DTNN, and the spectral line from Bruna through Defferrard to Kipf and Welling. Each came with its own notation, its own featurisation, its own benchmark. There was no way to tell whether one beat another because of its architecture or because of hand-built input features and a larger tuning budget. The application was real: the DFT calculation for a single nine-heavy-atom molecule in QM9 takes about an hour on one core of a Xeon E5-2660, so a learned surrogate is worth having. Nobody could say which of the eight designs deserved the engineering.

The move is to write all of them as three learned functions. A message function `M_t(h_v^t, h_w^t, e_vw)` produces what neighbour `w` sends to node `v` along edge `e_vw`; incoming messages are summed, `m_v^{t+1} = Σ_{w ∈ N(v)} M_t(·)`; a vertex update `U_t(h_v^t, m_v^{t+1})` folds the sum back into the node state. That runs for `T` rounds, after which a readout `R({h_v^T})` maps the whole set of node states to a graph-level prediction, order-free for the reason set out in 4.3. Every prior model is a choice of `M`, `U`, `R`. Spectral convolutions are one message function; interaction networks are another.

Having the slots made it cheap to try better fillings. The message function is an **edge network**: a small MLP maps the edge feature vector to a `d × d` matrix `A(e_vw)`, and the message is `A(e_vw) h_w`, so bond type conditions a linear map rather than being concatenated as a feature. The update is a GRU with the message as input, weights shared across the `T` steps. The readout is set2set. Two structural additions fight the fact that `T` rounds reach only `T` hops: virtual edges between non-bonded atoms, and a master node wired to every atom with its own width `d_master`. The `d × d` edge matrices are expensive, so node embeddings are split into `k` towers that message-pass separately and mix afterward; at `k = 8`, `n = 9`, `d = 200` this halved inference time.

The best model predicts to within chemical accuracy on 11 of 13 QM9 targets, and the framework is why the ablations mean anything — one codebase, one feature set, one tuning protocol. The message/update/readout triple became the vocabulary of the field and the object model of the libraries that followed.

> Most graph neural networks are the same algorithm with three plug-in functions, and naming the slots is what makes them comparable.

**The caveat:** QM9 caps at nine heavy atoms, and the paper says plainly that generalising to larger molecules looks hard, particularly with spatial information, because the pairwise distance distribution depends heavily on atom count and the most successful spatial variants build a fully connected graph whose incoming-message count grows with the number of nodes. No train-small, test-large experiment is reported; building one is listed as future work. The abstraction survived. The specific enn-s2s network is not what anyone runs now.
