**Scott Aaronson · 2011 · [Shtetl-Optimized](https://scottaaronson.blog/?p=762)**

Here is the puzzle, and you can watch it happen in a cup. Pour cream into coffee. At the start the picture is simple: white on top, black below. At the end it is simple again: uniform beige. In between, for a few seconds, the cream pulls into intricate tendrils, and the picture is genuinely complicated.

**Entropy — roughly, how disordered a thing is — rises through all three stages and never comes back down.** So whatever it is that goes up and then down again is not entropy. Sean Carroll raised exactly this while opening FQXi's *Setting Time Aright* conference, calling the missing quantity "interestingness", and this post of 23 September 2011 is the answer. Nobody had a definition of it.

The Kolmogorov complexity of the previous section is no substitute, and the reason is sharp: pure noise is incompressible, so complexity is *maximised* by the fully mixed cup. It tracks disorder, not structure. We need something that scores the tendrils high and both ends low.

**The first attempt is sophistication**, borrowed from the algorithmic statistics mentioned above. Instead of compressing the picture $x$ directly, split the description in two: name a set $S$ that contains $x$, then give an index pointing at $x$ within $S$. Formally $\operatorname{Soph}(x)$ is the smallest cost of describing such a set, restricted to sets in which $x$ looks like a perfectly typical member rather than a special one — the condition $K(x \mid S) \geq \log_2 \lvert S \rvert - c$. The point of the split is that **structure goes into the set and noise goes into the index, where it is charged nothing.** Check the two ends. A random string is a typical member of "all strings of length $n$", a set so cheap to describe that you need only write down $n$. A simple string sits in the one-element set $S = \lbrace x \rbrace$, also cheap. Both score low, correctly.

But sophistication never charges for the tendrils either, and the failure is instructive. Under a deterministic rule, the state at step $t$ can be printed by a short program: the starting condition, the rule, and the number $t$. So $\operatorname{Soph}$ can never exceed roughly $\log t$. Making the rule random does not help — the set of states reachable by time $t$ has the same short description, and the actual state is almost always a typical member of it. **A cheap set always exists, so the intricacy never gets billed.**

The fix is to stop allowing descriptions that take forever to unpack. **Complextropy** is the length of the shortest program that runs within a fixed time budget of $n \log n$ and outputs a roughly uniform sample from a set $S$ containing $x$ — with the further requirement that anyone trying to print $x$ within that same budget, even handed free samples from $S$, still needs at least $\log_2 \lvert S \rvert - c$ bits. The first bound kills the starting-condition-plus-$t$ shortcut, because replaying the dynamics to step $t$ blows the time budget. The second stops the measure from rising and never returning. Check the ends again: at $t = 0$ the one-element set is cheap, at equilibrium the set of states with the right cream fraction can be sampled quickly, and in between neither is available.

A folk intuition thereby became a real conjecture with a candidate measure and a model system to test it on: a grid of black and white pixels, mixed by repeatedly swapping a random neighbouring unlike pair. It belongs in this chapter because it states the chapter's premise out loud — compressed length measures structure only once you have fixed how much computation the decoder is allowed.

> Order and randomness are both cheap to describe; complexity is what is left once the description must be produced under a time bound.

**What did not survive:** nothing has been proved. Fifteen years on there is still no demonstration, either way, that complextropy rises and falls in any model system, and the 2014 attempt to show it empirically picked a model that turned out not to exhibit the effect — that is the next section. Bennett's logical depth, the other candidate that scores order and noise both low, is not weighed up in the post at all; Aaronson dismisses it only down in the comments, on the ground that an intricate state can sometimes be generated quickly, so depth need not peak in the middle.
