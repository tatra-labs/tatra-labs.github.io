**Scott Aaronson · 2011 · [Shtetl-Optimized](https://scottaaronson.blog/?p=762)**

Entropy increases monotonically toward equilibrium; Sean Carroll, opening FQXi's *Setting Time Aright* conference, pointed out that "interestingness" does not, and this post of 23 September 2011 answers him. Cream just poured into coffee is simple; fully mixed and beige it is simple again; in between the tendrils are intricate. Entropy rises through all three, so whatever rises and falls is not entropy — and it had no definition. The Kolmogorov complexity of the previous section is no substitute: noise is incompressible, so it is maximized by the fully mixed state. It tracks entropy, not structure.

His starting point is sophistication, from the algorithmic statistics above. Rather than compress `x` directly, split the description: a set `S` containing `x`, plus an index into `S`. `Soph(x)` is the smallest `K(S)` over sets `S` with `x ∈ S` and `K(x|S) ≥ log2|S| − c` — the sets in which `x` looks like a generic member. Structure goes into `S`; noise goes into the index, free. A random string is generic in `{0,1}^n`, an `S` costing only the bits to write `n`; a simple string sits in the singleton `S = {x}`. Both are unsophisticated.

Sophistication does not charge for the tendrils, and the failure is instructive. Under a deterministic rule the state at step `t` is printed by a short program — initial condition, transition rule, `t` — so `Soph` never exceeds `log t + c`. A stochastic rule does not help: the set `S(t)` of reachable states has the same short description, and the actual state is almost always a generic member of it. A cheap `S` always exists, so the boundaries are never paid for. The fix is to bound computation on both sides. **Complextropy** is the length of the shortest program that runs in `n log n` time and outputs a nearly-uniform sample from a set `S` with `x ∈ S`, such that any program printing `x` in `n log n` time, given an oracle for uniform samples from `S`, still needs at least `log2|S| − c` bits. The sampler bound kills the initial-condition-plus-`t` shortcut; the reconstructor bound stops the measure rising and never coming back down. At `t = 0` a singleton `S` is cheap; at equilibrium the set of states with the right cream fraction samples fast; in between, neither.

A folk intuition thereby became a conjecture with a candidate measure and a model system: a grid of black and white pixels, mixed by swapping a random adjacent unlike pair. It belongs here because it states the chapter's premise: compressed length measures structure only once the decoder's compute budget is fixed.

> Order and randomness are both cheap to describe; complexity is what is left once the description must be produced under a time bound.

**What did not survive:** nothing has been proved. Fifteen years on there is no demonstration, either way, that complextropy rises and falls in any model system, and the 2014 empirical attempt picked a model that turned out not to show the effect — the next section. Bennett's logical depth, the other candidate scoring order and noise both low, is not weighed in the post; Aaronson dismisses it only in the comments, on the ground that an intricate state can be generated quickly, so depth need not peak.
