# 20.7 Boltzmann Machines for Structured or Sequential Outputs

Two short constructions extending Boltzmann machines to problems where the output has internal structure
or unfolds over time.

## Conditional models

The first extension conditions an RBM on an input. In the **conditional RBM**, the biases of the visible
and hidden units are not fixed parameters but functions of some conditioning variable $x$ — typically
produced by a neural network. The model then represents $p(y \mid x)$ with the same energy-based
machinery, and the conditioning enters by shifting the energy landscape rather than by changing its shape.

This is useful when the output variables are dependent on one another: a structured output such as a
segmentation or a set of joint angles has correlations that independent per-variable predictions cannot
capture, and an RBM over the outputs represents them.

## Sequences

The **RNN-RBM** applies the same idea over time. A recurrent network reads the sequence and, at each step,
emits the parameters — the biases — of an RBM over the observation at that step. The recurrent network
carries the temporal context; the RBM models the structure within a single time step.

The book's motivating application is polyphonic music, where several notes sound simultaneously and are
strongly dependent on each other, so a model emitting independent per-note probabilities is inadequate.
Training back-propagates through the recurrent network using the RBM's approximate gradient.

## My take

The division of labour is the interesting part and it is a genuinely good design. The recurrent network
handles the dependence **across** time steps, where a directed factorisation is natural and cheap; the RBM
handles dependence **within** a step, where the variables are simultaneous and no ordering is natural.
Each formalism is used where it fits.

The problem it solves has not gone away. Predicting several outputs that are dependent on one another,
from one context, is the structured-prediction problem, and the independent-per-output softmax that most
systems use is wrong whenever those outputs are correlated. Polyphonic music is the clean example, and
multi-label classification and joint pose estimation have the same shape.

What replaced this is a directed answer rather than an undirected one. The dominant approach now is to
**order the outputs and factorise them autoregressively** — predict note one, then note two given note
one, and so on — which represents the same dependencies exactly, by the chain rule of 3.6, and requires no
partition function. It costs an arbitrary ordering and a sequential decode, and it is enormously easier to
train and evaluate.

That comparison is a fair summary of the whole chapter's fate. The undirected model represents the
dependency structure without imposing an artificial order, which is the more faithful thing to do; the
directed model imposes the order and gets exact likelihoods, cheap sampling and stable training in
exchange. The field took the trade every time.
