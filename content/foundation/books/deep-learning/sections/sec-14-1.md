# 14.1 Undercomplete Autoencoders

An autoencoder is a network trained to copy its input to its output. Stated that way it sounds useless,
and the chapter's first section explains what makes it not so.

## The construction

An autoencoder has two parts: an **encoder** $h = f(x)$ producing a code, and a **decoder** $r = g(h)$
producing a reconstruction. Training minimises a loss $L(x, g(f(x)))$ penalising the reconstruction for
differing from the input.

The point is not the copy. An autoencoder that copied perfectly would be worthless; what is wanted is a
model that copies only **approximately**, and only for inputs resembling the training data, so that the
code $h$ is forced to retain the useful structure and discard the rest.

## Undercompleteness

The simplest way to force that is to make the code **smaller than the input**. An autoencoder whose code
dimension is less than its input dimension is **undercomplete**, and learning to minimise reconstruction
error under that constraint forces the code to capture the most salient factors of variation.

The book gives the exact link to the previous chapter: when the decoder is linear and the loss is mean
squared error, an undercomplete autoencoder learns to span the **same subspace as PCA**. It does not
necessarily learn the principal components themselves — nothing orders or orthogonalises them — but the
subspace is the same. With nonlinear encoders and decoders it becomes a strictly more powerful
generalisation of PCA, capable of learning a curved manifold rather than a flat one.

## The failure mode

Capacity must be limited relative to the task. The book states the failure directly: an encoder and
decoder given too much capacity learn to copy the input without extracting anything useful. In the extreme
case a one-dimensional code suffices if the encoder is powerful enough — it can map each training example
to its index and the decoder can map the index back — a perfect reconstruction that has learned nothing
about the data distribution.

## My take

That last observation is the most important thing in the chapter and it is stated in a single paragraph.
**Reconstruction error is not a measure of representation quality.** A model can achieve zero
reconstruction loss by memorising, and the objective gives no signal distinguishing that from
understanding. Every technique in the rest of Chapter 14 exists to close the gap between the objective
being optimised and the property actually wanted.

This generalises well beyond autoencoders and is worth holding as a general suspicion. Whenever a proxy
objective is optimised in place of an unmeasurable goal, the question is what degenerate solution achieves
a perfect score, and whether anything prevents the model from finding it.

The PCA connection is also the cleanest example in the book of the general pattern that a nonlinear
neural version of a classical method usually contains the classical method as a special case. Linear
encoder plus squared error gives PCA; make the layers nonlinear and the subspace becomes a manifold. It is
the same relationship as logistic regression to a classifier network, and it is a good way to sanity-check
that a new architecture reduces to something known.
