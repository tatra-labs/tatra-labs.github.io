# 17.4 Gibbs Sampling

The concrete MCMC algorithm used with energy-based models, and the reason the restricted Boltzmann
machine has the shape it does.

## The algorithm

Rather than designing a transition operator by hand, Gibbs sampling constructs one from the model's own
conditionals. Select a variable $x_i$ and resample it from

$$
p\left( x_i \mid x_{-i} \right)
$$

its conditional distribution given all the other variables. Repeat, cycling through the variables or
choosing them at random.

The step is cheap for a graphical model, because the conditional depends only on the variable's
**neighbours** in the graph — the partition function cancels, since it is the same in the numerator and
denominator of the conditional. That cancellation is what makes Gibbs sampling possible for models whose
joint distribution cannot be evaluated.

## Block Gibbs

When a group of variables is **conditionally independent given the rest**, the whole group can be
resampled simultaneously. In a restricted Boltzmann machine the hidden units are conditionally
independent given the visible units and vice versa, so an entire layer updates in one step — a single
matrix multiply followed by independent draws.

This is **block Gibbs sampling**, and it converts what would be thousands of sequential single-variable
updates into two matrix operations per sweep.

## My take

The block Gibbs property is the whole reason the RBM is bipartite, and reading Sections 16.7 and 17.4
together makes the design legible. A general Boltzmann machine with connections within a layer would
require updating one unit at a time, which is sequential and slow. Removing the within-layer connections
makes each layer conditionally independent given the other, which turns a sequential scan into a matrix
multiply.

That is an architecture designed backwards from a sampling algorithm — the model was restricted so that
its inference step would fit a parallel machine. It is the same kind of reasoning that produced attention
two decades later, and it is worth noticing that the field has repeatedly chosen models for the shape of
their computation rather than for the shape of the data.

The limitation is the one carried over from 17.3, and block updates do not fix it. Gibbs sampling changes
one variable, or one layer, at a time, so it moves through state space by a **random walk**. Reaching a
distant mode requires a sequence of individually-probable steps, and if the path between two modes passes
through low-probability territory, no amount of block structure helps — the chain will not take the
journey. Section 17.5 is about exactly this, and it is the failure that made training Boltzmann machines
unreliable.
