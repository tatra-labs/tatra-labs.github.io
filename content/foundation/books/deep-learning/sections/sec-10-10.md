# 10.10 The Long Short-Term Memory and Other Gated RNNs

The section that describes what actually worked. Gated recurrent networks were the most effective
practical sequence models at the time of writing, and the LSTM held that position for twenty years.

## The idea

Leaky units in 10.9 accumulate information over a time scale fixed in advance. The gated units here make
two changes: the accumulation weight is **computed by the network from the current context** rather than
fixed, and the unit can **clear** its accumulated state once it has been used.

Deciding when to forget is the operative capability. A model reading a story should reset its accumulated
state when a new scene begins, and no fixed time constant can express that.

## The LSTM cell

Each cell contains an internal state $s$ with a linear self-loop, and three sigmoid gates controlling it.
For cell $i$ at step $t$, each gate is an affine function of the current input and the previous hidden
state, squashed to $(0, 1)$:

$$
f_i^{(t)} = \sigma\left( b_i^f + \sum_j U_{i,j}^f x_j^{(t)} + \sum_j W_{i,j}^f h_j^{(t-1)} \right)
$$

with analogous expressions and separate parameters for the external input gate $g$ and the output gate
$q$. The state updates as

$$
s_i^{(t)} = f_i^{(t)} s_i^{(t-1)} + g_i^{(t)} \sigma\left( b_i + \sum_j U_{i,j} x_j^{(t)} + \sum_j W_{i,j} h_j^{(t-1)} \right)
$$

and the output is the state, squashed and gated:

$$
h_i^{(t)} = \tanh\left( s_i^{(t)} \right) q_i^{(t)}
$$

Read the state update against the leaky unit of 10.9 and the design is clear: the **forget gate** $f$ has
replaced the fixed $\alpha$, so the time constant is now dynamic and conditioned on the data. The
**input gate** $g$ decides whether to write, and the **output gate** $q$ decides whether the state is
exposed to the rest of the network at all.

## GRU

The gated recurrent unit simplifies this. A single **update gate** performs the roles of the forget and
input gates simultaneously, and a **reset gate** controls how much of the previous state enters the
candidate update. There is no separate output gate — the state is the hidden unit.

The book reports the finding that has held up: many architectural variants have been investigated, and
none consistently beats the LSTM across a range of tasks. The forget gate is identified as the critical
component.

## My take

The forget-gate result is the sharpest empirical finding in the chapter. Systematic architecture searches
over gated variants found that removing the forget gate hurts and that most other modifications do not
matter, which says the essential invention was **learned, content-dependent forgetting** — not gating in
general and not the specific arrangement of three gates.

The mechanism by which LSTM helps is worth stating precisely, because the common explanation is loose. The
gradient along the cell state passes through multiplication by the forget gate at each step, not through
a weight matrix. If the gate stays near one, the factor stays near one and the gradient neither vanishes
nor explodes over that stretch. This is why the forget-gate bias should be initialised positive, per
Section 8.4 — it starts the cell in remembering mode, and a cell that starts by forgetting never learns
that it should not.

What the section could not know is how the story ends. The LSTM was displaced not because a better
recurrence was found but because the recurrence itself was the problem: the sequential dependency makes it
unparallelisable, per 10.2, and that ceiling could not be raised. The interesting coda is that recurrence
returned, in the state-space models — S4, Mamba — which reintroduce a linear recurrence deliberately
designed to be computable in parallel. The gate is back, and it is arranged so the sequential scan can be
turned into a convolution.
