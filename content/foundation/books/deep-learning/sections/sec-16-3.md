# 16.3 Sampling from Graphical Models

A short section with a sharp contrast: sampling from a directed model is trivial, and sampling from an
undirected one is not.

## Ancestral sampling

For a directed model, sort the variables in **topological order** so every variable follows its parents,
then draw each in turn from its conditional distribution given the already-sampled parents. One pass,
exact samples, cost linear in the number of variables.

The book notes two limitations. It works only for directed models, and it does not straightforwardly
support **conditional** sampling — drawing from $p(x_i \mid x_j)$ when $x_j$ comes *after* $x_i$ in the
ordering requires either rejection sampling, which is expensive, or a different method entirely.

## Gibbs sampling

For an undirected model there is no ordering to exploit, because the factors are not conditionals. The
standard approach is to construct a Markov chain whose stationary distribution is the model, and run it.

**Gibbs sampling** does this by repeatedly selecting one variable and resampling it from its conditional
distribution given all the others — which is cheap, because that conditional depends only on the
variable's neighbours in the graph. Sweeping through all variables repeatedly, the chain converges to the
target distribution.

The book is careful about the cost. Convergence is **asymptotic**: the samples are only approximately from
the model, and there is no reliable way to know how many steps are enough. The chain must be run for some
burn-in period, and consecutive samples are correlated.

## My take

This section is the clearest single demonstration of the asymmetry that decided which model families
survived, and it is worth stating in one line: **a directed model samples exactly in one pass, and an
undirected model samples approximately after an unbounded number of passes.**

Everything about the relative fortunes of these families follows. Training a generative model requires
samples — Chapter 18 will show that the gradient of an undirected model's log-likelihood contains an
expectation under the model itself — so a family that cannot sample cheaply cannot be trained cheaply.
Boltzmann machines pay this cost on every gradient step. Autoregressive models never pay it at all.

The conditional-sampling limitation of ancestral sampling is worth noting too, because it did not go
away. A language model can complete a prefix in one pass and cannot fill in a gap given both sides
without machinery — infilling requires either a rearranged training objective or an iterative procedure.
That is the same restriction described here, still present, in the most widely deployed generative models
there are.

The one place Gibbs-style iteration won is diffusion, and it is worth seeing why the tradeoff is different
there. A diffusion model also samples by running an iterative chain, but the chain has a **fixed, known
length** and requires no burn-in or convergence diagnosis, because the noise schedule is designed in
advance rather than emerging from a stationary distribution. It buys the expressiveness of iterative
sampling without the open-ended cost that makes Gibbs sampling unusable at scale.
