# 13.3 Slow Feature Analysis

A linear factor model with a prior that is not about the distribution of the features but about how they
change over **time**.

## The slowness principle

The organising idea is that the important characteristics of a scene change slowly compared with the
individual measurements describing it. A zebra crossing the visual field flips individual pixels between
black and white many times a second; the fact that there is a zebra changes slowly. A feature that varies
slowly is therefore more likely to correspond to something meaningful.

Formalised, the regularisation term added to the objective is the average squared change of each feature
across consecutive time steps:

$$
\lambda \sum_t \left( f\left( x^{(t+1)} \right) - f\left( x^{(t)} \right) \right)^2
$$

## The algorithm

**Slow feature analysis** applies this principle with $f$ constrained to be linear, which makes the
problem solvable in closed form. The features are found by minimising the slowness objective subject to
three constraints, all of which are necessary to avoid degenerate answers:

- **Zero mean**, which makes the solution unique.
- **Unit variance**, without which the trivially slowest feature is a constant.
- **Decorrelation**, which forces the features to be distinct rather than all recovering the same slow
  signal.

The features are learned in order, each slowest subject to being decorrelated from those already found —
so the method has an inherent ordering, like PCA. The book notes that SFA is typically applied after a
nonlinear expansion of the input, since the linear version alone is limited, and that a deep version can
be trained greedily.

The theoretical attraction the book highlights is unusual for this part of the field: SFA is one of the
few feature-learning algorithms for which it is possible to say analytically which features it will
learn, given assumptions about the data-generating process.

## My take

The slowness principle is a genuinely good prior and the algorithm built on it is not the reason to
remember this section. SFA never scaled — the closed-form linear solution is its main attraction and its
main limitation, and the nonlinear expansions needed to make it useful reintroduce every difficulty it
was avoiding.

The principle, though, came back with force. **Temporal consistency** as a self-supervised objective —
train a representation so that nearby frames of a video map to similar vectors — is the same idea, and it
is a workhorse of modern video representation learning. So is the constraint structure: every method of
this kind must prevent collapse to a constant, which is exactly what the unit-variance and decorrelation
constraints do here.

That is the connection worth making. The collapse problem in contrastive and non-contrastive
self-supervised learning — where a network trained only to make similar things similar discovers that
mapping everything to one point is optimal — is the degeneracy this section's constraints were designed to
rule out. The modern answers are negative pairs, stop-gradients, and variance-covariance regularisation.
The last of those, in VICReg, is literally the unit-variance-plus-decorrelation pair from this 2002
algorithm, rediscovered for deep networks two decades later.
