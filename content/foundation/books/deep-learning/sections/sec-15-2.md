# 15.2 Transfer Learning and Domain Adaptation

Using what was learned in one setting to improve performance in another. The section is mostly taxonomy,
and the taxonomy is useful because the cases have genuinely different requirements.

## The cases

**Transfer learning.** The input distribution changes and the task changes, but they share underlying
structure — so a representation learned for one is useful for the other. The book's example is
recognising cats and dogs, then transferring to ants and wasps: the low-level visual features are shared
even though the categories are not.

**Domain adaptation.** The task stays the same and only the input distribution changes — a sentiment
classifier trained on reviews of media, applied to reviews of appliances. The mapping from input to label
is unchanged; the vocabulary is not.

**Concept drift** is described as a form of transfer learning where the distribution changes gradually
over time.

**One-shot learning** is possible when the representation cleanly separates the underlying classes, so a
single labelled example suffices to identify a region of the space. **Zero-shot** or **zero-data**
learning requires a third variable — a description of the task or class — so the model can generalise to
a class it has never seen an example of, given a specification of what it is.

## Which layers transfer

The book notes an asymmetry that determines how transfer is done in practice. When the input distribution
changes but the task is the same, the **lower layers** transfer, since they capture generic properties of
the input. When the task changes but the input is the same, it is the **upper** layers that need
replacing, and the shared representation is reused beneath them.

## My take

The zero-shot discussion is the most prescient passage in the chapter, and it is short. The book's framing
is that zero-shot learning requires a representation of the task itself to be provided as an input, so
the model can condition on a description rather than requiring examples — and gives the case of learning
from a textual description of a class never seen.

That is a description of prompting, written before it existed. A modern language model performs zero-shot
tasks exactly this way: the task specification is part of the input, the model conditions on it, and no
gradient step occurs. The book identifies the mechanism as the requirement for a shared representation
space in which task descriptions and inputs can be related — which is also, precisely, how CLIP does
zero-shot image classification, by embedding images and text descriptions into one space.

The layer asymmetry is the practical takeaway and it remains the operating rule. Fine-tuning replaces the
head and adapts the top; feature extraction freezes the bottom. What has changed is how much gets
adapted: parameter-efficient methods such as LoRA update a small low-rank correction spread throughout the
network rather than a block of layers, which does not fit the low/high split this section describes and
works better than either extreme.

The broader point worth keeping is that transfer is not one technique. Which case you are in — new inputs,
new task, or both — determines what to reuse, and getting that wrong is why transfer sometimes fails
outright rather than merely underperforming.
