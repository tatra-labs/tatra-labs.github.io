# 11.2 Default Baseline Models

Once the metric is chosen, the next decision is what to build first. The book's answer is: something
boring, quickly, so that later choices can be measured against it.

## Start simple

The first question is whether deep learning is needed at all. For a problem that is "AI-complete" —
object recognition, speech, translation — a deep model is the right starting point. For many other
problems, the book says plainly that a simple statistical model such as logistic regression is the right
first attempt.

## The recipe

If a deep model is warranted, the recommendations are specific:

- **Activation:** a rectified linear unit or one of its variants.
- **Optimiser:** SGD with momentum and a decaying learning rate, using linear decay, exponential decay, or
  halving the rate each time validation error plateaus. Adam is named as the other reasonable default.
- **Normalisation:** batch normalisation, and the book advises introducing it promptly if optimisation
  appears problematic.
- **Regularisation:** some from the start, unless the training set contains tens of millions of examples
  or more. Early stopping should be used almost universally; dropout is an excellent default, with batch
  normalisation sometimes making it unnecessary.

Architecture follows the data structure. Convolutional networks with piecewise-linear units for inputs
with known topological structure; gated recurrent networks for sequences.

## Copy what works, and reuse what exists

Two further recommendations. If the task resembles one that has been studied extensively, **copy the
model and algorithm** known to work well on it — often copying a trained model outright. And if the task
is in a domain where unsupervised learning is known to help, such as natural language processing, it is
worth including; otherwise, only if the problem is semi-supervised.

## My take

"Start with a strong baseline you did not design" is advice that survives intact, and the reason is worth
stating: without a baseline, every subsequent measurement is uninterpretable. A model that reaches 87% is
neither good nor bad until something else has been run on the same data.

The specific recipe has aged in a predictable direction. Adam is now the default rather than the
alternative; batch normalisation has been displaced by layer normalisation in anything sequence-shaped;
and the architecture guidance would now read "start with a transformer" for nearly everything, including
the cases the book routes to convolution and recurrence.

The recommendation that has grown most in importance is the one given least space. **Copy a trained
model.** In 2016 that meant taking an ImageNet-pretrained network and fine-tuning it; today it is the
default way any applied problem is approached, and training from scratch is the unusual choice requiring
justification. The book mentions it in a sentence and treats the from-scratch case as normal, which is the
clearest sign of its vintage.

The unsupervised-pretraining hedge is worth reading twice. The authors recommend it for natural language
specifically and are otherwise sceptical, per Section 15.1. That was an accurate read of the evidence in
2016 and it happened to name the exact domain where the technique was about to become everything.
